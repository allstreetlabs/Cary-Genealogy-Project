# Evidence and editorial standards

Use separate fields for proposition status, source type and examination access.

| Claim status | Meaning |
|---|---|
| testimony | A reported family account; name the informant only if public clearance permits |
| described_record | A document is described; underlying item has not been examined |
| published_support | A published source supports the proposition; not automatically independent or conclusive |
| documentary_statement | Examined document states this; event accuracy still needs assessment |
| conditional | An inference whose dependencies must be stated |
| unresolved | A question or conflicting attribution remains open |
| verified | Claim-specific written proof assessment addressing identity, alternatives and conflicts |

Internal T/D/I/OPEN map to testimony/described_record/conditional/unresolved. A published claim remains published support even when the page has been read. Never upgrade to verified by receiving a screenshot or finding several copied trees.

Source `access`: `examined_publication`, `examined_derivative`, `described_unexamined`, `reference_only`, or `withheld`. Access concerns the particular representation, not its underlying original. A private source can have public metadata without an excerpt or downloadable file.

Preserve explicit citations, page/entry identifiers, date conventions and ambiguities. Registration quarter is not exact birth date; probate is not date of death; a marriage is not proof that a particular child was born to that wife. Missing entries in selective pedigrees do not disprove a relative's existence. Titles, landownership, court service and heraldic entitlement are distinct propositions.

Sources may depend on each other. Two websites copying one biography count as one source tradition, not two independent witnesses. If a source was inspected by a specialist rather than the public editor, say so. Preserve both sides of a conflict and identify the resolving evidence.
