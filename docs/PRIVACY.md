# Public publication boundary

This is a public repository. Branches, forks, issues, pull requests, logs and commit history may be copied by others. Deleting a file later cannot guarantee withdrawal of all copies.

The initial dataset excludes living people, their relationships to private records, contact details, DNA amounts, adoption details, private letters and uploaded family images. Internal Library IDs, private download paths, original email headers, residential addresses and unredacted documents are not public citations.

Only data explicitly marked public, with a recorded publication basis, is eligible for the website. For living people, the current data format prohibits records altogether. A future opt-in directory needs a separate consent-based model and access controls; do not add people to this historical dataset to work around that boundary.

Use minimal public source metadata when an underlying source is private. Mark it withheld, do not invent a public citation or imply independent verification. Deceased subjects still require appropriate care for information about living relatives, copyright and provenance.

Sensitive evidence needs a separate private intake system. Do not use a public GitHub issue as an upload form. No private submissions, login, member directory or messaging service is configured by this starter.

If sensitive material is posted accidentally, notify a maintainer without repeating it publicly. Remove access, assess history/logs/caches and coordinate any necessary repository history cleanup; never promise complete erasure.
