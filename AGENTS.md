# Guidance for automated contributors

This is a public research-data repository, not the private HQ archive. Read README, CONTRIBUTING, docs/PRIVACY and docs/EVIDENCE before editing. Do not upload internal masters, raw correspondence, living-person records, DNA data, private storage IDs or family images without an explicit public publication basis.

Preserve HQ IDs. Do not allocate competing permanent IDs, invent ancestors, resolve disputes by majority vote, or promote hypotheses to verified. Changes to historical conclusions need source-specific assessment and HQ reconciliation. A public PR is public before merge.

Keep the site renderer in a separate repository. Run `python3 scripts/validate.py` and `python3 -m unittest discover -s tests` before proposing data/model changes. Validation is not proof of genealogy, privacy clearance or copyright permission. No site deployment or background synchronization is configured here.
